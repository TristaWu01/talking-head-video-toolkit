# Fonts

Put your font files here and name them in `library/brand/theme.toml`.

The default theme expects **Noto Sans SC Bold** (`NotoSansSC-Bold.ttf`), which covers both Chinese and Latin letters. It's free under the SIL Open Font License. Download it from [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Sans+SC) and copy `static/NotoSansSC-Bold.ttf` into this folder.

Any other font works too. If your videos are in Chinese, Japanese or Korean, the main font must include those characters.

Font files are not committed (see `.gitignore`). Check a font's licence before you share it.
